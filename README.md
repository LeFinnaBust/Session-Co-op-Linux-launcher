A native Linux / Steam Deck launcher that installs and runs the **Session Co-op** multiplayer mod for *Session: Skate Sim*.

 <img width="1920" height="1080" alt="Screenshot_20261102_232939" src="https://github.com/user-attachments/assets/a50c87b8-b29a-43ee-b63d-2affe7877e67" />




The Co-op mod is built for Windows and doesn't work under Proton out of the box. 
This launcher handles the Linux-specific 
setup so the mod runs the same as it does on Windows.

## Features
- One click install mod manager within the linux co-op launcher https://github.com/rodriada000/SessionModManagerCore. <img width="1920" height="1080" alt="Screenshot_20261102_041820" src="https://github.com/user-attachments/assets/571d6027-9401-45ec-ac05-87a56feb224c" />
- Works with the Steam version, or any other copy (Epic, GOG, etc.) by picking your game folder. No Heroic, Lutris or Bottles needed.
- One-click install, setup checklist, and a connection test.
- No extra dependencies. Runs on the Python that ships with SteamOS.

## Requirements

The mod's files are **not included**. Download the official `Session-Coop-Complete.zip` from 
the [Session Co-op Discord](https://discord.gg/Fb5haGntd) and place it in the same folder as the AppImage.

## Usage

1. Install Session and launch it once.
2. Put the AppImage and the mod zip in the same folder, and make the AppImage executable.
3. Open the AppImage, press **Install / Repair**, then **Play**.
